# Exact all-subsets layer (1.1.0)

Run from the archive root with Node >=18 and Python:

```text
python validate.py
python verify.py
python v1_1/archive.py safeguards
node v1_1/exact/gosh/tests/exact-enum.test.cjs
node v1_1/exact/gosh/tests/exact-compare.test.cjs
```

`ARCHIVE_V1_1_ONLY=1 python validate.py` skips the unchanged v1.0 comparison
and legacy numeric replay, verifies both inventories, then runs this exact tier.
Set the environment variable using your shell's syntax (in PowerShell:
`$env:ARCHIVE_V1_1_ONLY='1'`). No R references are regenerated by these commands.
The standalone `node v1_1/exact/replay.cjs` verifies the corpus/reference manifest;
the Python entrypoint additionally verifies the engine, scripts and complete layer.

The saved independent R oracle covers 17 configurations (k=16..24), each FE/DL:
34 results, `EXACT R 345842/345842`. Forced metafor covers all nine
configurations with k<=20: 18 results, `EXACT METAFOR 182826/182826`.
These totals compare aggregate summaries, type-7 quartiles, every 100x100
density cell and per-study summaries; they are not individual-subset check totals.
Counts and grid cells are exact. Continuous quantities use
`abs(app-ref)/max(1,abs(ref)) <= 1e-9`.

The application files in `gosh/` are Git blob snapshots from
`1e3ef389cdfbce7c735c32e2794e67d3cbefb622`, recorded in
`../PROVENANCE.json`. This is an offline numerical snapshot, not a complete
standalone website; page UI dependencies are not all duplicated here.
The original inline engine is executed by the unmodified
`gosh/validate/replay-numeric.cjs`, with base 533726/533726 and extras
584662/584662. These exclude browser geometry and UI checks.

The R generators assert R 4.6.0 and jsonlite 2.0.0; the metafor generator
also asserts metafor 5.2.1. Independent R uses two-pass residual formulae and
retains all subset values for quantiles. Metafor explicitly calls
`gosh(..., subsets=2^k-1, parallel="no")` and verifies complete, distinct membership.
Optional regeneration, using separately installed packages and fresh work directories:

```text
Rscript v1_1/exact/generate-exact-r.R v1_1/exact/corpus.json .validate-work/exact-r .validate-work/reference-r.json
Rscript v1_1/exact/generate-exact-metafor.R v1_1/exact/corpus.json .validate-work/exact-metafor .validate-work/reference-metafor.json 20
```

Set `R_ENVIRON_USER` to an empty file and `R_LIBS_USER`/`R_LIBS` to the
installed package libraries before launching R. Generators resume checkpoints;
use fresh directories for a fresh computation. Saved references remain authoritative
for replay, and regeneration does not silently replace or repin them.

## Timing data

`timings.csv` has one row per configuration/model, mechanically extracted from
`evidence/historical-exact-audit.json`. Blank metafor times mean not run (k>20).
App Node milliseconds include engine creation, both passes, quantile sorting and
summary construction; metafor seconds cover `gosh()` only, which retains all fits
and membership. Independent-R seconds cover its fitting and summaries. Measurements
are historical observations on a shared Windows host, not a controlled benchmark
or a speed guarantee. Some R generation overlapped the independent oracle;
the Node measurements followed reference generation. Current-run times are in
the replay audit under `outputs/v1_1/`.

## Planted defects

With `ARCHIVE_V1_1_ONLY=1`, run:

```text
python validate.py --plant estimate
python validate.py --plant drop
```

Both must exit nonzero and print failed counts. `estimate` changes one actual
subset estimate by +1e-6: the maximum-effect singleton in the first FE result.
An in-memory source injection applies that change in both enumeration passes;
the pinned engine file is never edited. The extreme changes the reported maximum,
avoiding dilution of an interior estimate across millions of subsets. This control
does not claim that every arbitrary single-subset error is detectable by aggregates.
`drop` uses the upstream control: remove the full-set subset from each result,
adjusting its counts, means and grid. Expected failures are R 343643/345842 and
metafor 181759/182826. Weight and grid controls are also retained.

## Preservation and provenance

The root `SOURCE_SHA256.json`, `INPUT_SHA256.json`, original application, data,
results, analysis scripts and `validate.R` are unchanged. The four updated root
metadata files have their exact original bytes in `../legacy-metadata/`.
`../archive.py` reconstructs a temporary v1.0 view from those files and all other
original paths, checks every old pin, and executes the unmodified legacy scripts.
Derived outputs are copied into that view. No Git repository is required at runtime.
`../SOURCE_SHA256.json` separately pins this layer and the updated root entrypoints
and metadata. `python verify.py` enforces coverage of both inventories.

No fresh R generation, browser validation, new statistical method, release
publication or DOI assignment is claimed by this archive update.
